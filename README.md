# 🛡️ Protect Your Device

A responsive one-page web resource introducing free antivirus options and cybersecurity best practices for new remote employees using personal Windows computers.

## Live Site

After GitHub Pages is enabled:

`https://kaylaereyes.github.io/protect-your-device/`

## Purpose

This webpage is the visual-summary component of a Technical Writing assignment. It condenses the related oral presentation into a scannable resource for people who attended and those who could not attend.

## Audience

New remote employees using personal computers rather than employer-provided equipment.

## Run Locally in IntelliJ IDEA

1. Open this project folder in IntelliJ IDEA.
2. Open `index.html`.
3. Press `Alt + F2`, or right-click `index.html` and select **Open in Browser**.
4. Choose your preferred browser.
5. Save changes and refresh the browser.

You can also double-click `index.html` in File Explorer to open it directly.

## Publish with GitHub Pages

1. Create a GitHub repository named `protect-your-device`.
2. Upload or push all project files.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Select **Save**.
7. Wait for deployment to complete.
