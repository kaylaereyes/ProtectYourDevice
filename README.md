## Overview

Protect Your Device is a responsive educational website designed to help new remote employees better understand common cybersecurity threats and free antivirus solutions when using personal computers for work.

The website emphasizes clear technical communication through modern web design, semantic HTML5, responsive CSS3, accessibility considerations, and deployment using GitHub Pages.

## Target Audience

New remote employees using personal computers rather than employer-provided equipment.

## Features

- Responsive mobile-friendly layout
- Modern semantic HTML5 structure
- CSS Grid and Flexbox layouts
- Antivirus comparison cards
- Cybersecurity best practices
- External educational resources
- APA reference section

## Technologies

- HTML5
- CSS3
- Git
- GitHub Pages
